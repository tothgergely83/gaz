Gázóra Leolvasás

Az app Google Sheets-et használ az adatok tárolásához. Először egy Google OAuth Client ID szükséges.

Egyszeri beállítás – Google Cloud Console

  1. Nyissa meg: console.cloud.google.com
  2. Hozzon létre egy projektet (pl. "Gázóra")
  3. APIs & Services → Enable APIs → Google Sheets API engedélyezése
  4. APIs & Services → Credentials → Create Credentials → OAuth 2.0 Client ID
  5. Alkalmazás típusa: Web application
  6. Authorized JavaScript origins:
  7. Másolja be az alább kapott Client ID-t
